# Auto Lot Saver

Расширение Chrome/Opera для сохранения выбранного автомобильного лота в папку пользователя. Оно работает на страницах, доступных авторизованному пользователю, и не передает данные на внешний сервер.

## План и архитектура

Стек: Chrome/Opera Manifest V3, JavaScript без сборщика, File System Access API, `fetch`, JSON-LD и DOM-парсинг. `activeTab` и content script используются только для текущей вкладки. Для новых сайтов можно добавлять адаптеры в `content.js` по домену, не меняя popup.

```text
auto-lot-saver/
├── manifest.json   # разрешения, домены и popup
├── popup.html      # интерфейс расширения
├── popup.css       # стили
├── popup.js        # выбор папки, создание каталога, запись TXT и фото
├── content.js      # router: выбирает адаптер по домену, общий fallback-парсер
├── parsers/        # отдельные адаптеры сайтов
│   ├── remktg.js   # точный парсер Remarket Arval
│   ├── efl.js      # адаптер EFL
│   ├── otomoto.js
│   ├── auto1.js
│   ├── ayvens.js
│   ├── arval-autoselect.js
│   └── bca.js
└── README.md       # план, ограничения и установка
```

## Адаптеры сайтов

При сохранении лота `content.js` определяет текущий домен и вызывает адаптер из `parsers/`. Это позволяет дорабатывать один сайт без риска изменить работающий сбор данных с другого. `remktg.arval.com` извлекает данные из `app-main-characteristics-card` и записывает основные характеристики, регистрацию, место хранения, топливо, число мест и экологические данные. Для нового поведения сайта следует менять только соответствующий файл в `parsers/`.

Алгоритм: пользователь открывает лот, нажимает значок расширения, выбирает папку назначения, затем нажимает «Сохранить лот». Создается каталог с безопасным именем объявления, в нем `info.txt` и фотографии `1.jpg`, `2.jpg` и далее. Сначала используются JSON-LD-данные страницы, затем подписи и значения из DOM. Для разных сайтов предусмотрен общий fallback, который покрывает типовую разметку; при изменении верстки конкретного сайта его селекторы нужно уточнить.

## Установка в Windows 10/11

1. Распакуйте архив проекта в постоянную папку, например `C:\\Tools\\auto-lot-saver`.
2. Откройте Chrome и перейдите на `chrome://extensions` (в Opera: `opera://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку, где лежит `manifest.json`.
5. Закрепите Auto Lot Saver на панели браузера.
6. Войдите на поддерживаемый сайт, откройте конкретный лот, нажмите значок расширения, выберите папку и нажмите «Сохранить лот».

Примечание: сайты могут менять DOM, ограничивать загрузку изображений или использовать защищенные URL. В таком случае данные страницы останутся доступными, но отдельные фото могут быть пропущены; тогда для сайта нужен отдельный адаптер селекторов.
